Step-by-step plan

0. pre-requirements

    - each episode of podcast has to be already edited and exported as the set of mono channel .wav files with standardized name, e.g. S01E01_John.wav and S01E01_Paul.wav for the episode with John and Paul as speakers. All recordings have to be edited on the same timeline to prevent shifts and mismatches

    - folder names are also standardized, e.g. first episode of the first series should be in folder named "S01E01"

1. Requirements:

    - the program has to process multiple (2 or more) .wav files for each episode

    - transcription is done using whisper, generating both per-word and per-sentence transcripts with accurate timestamps

    - timestamps for each file should be saved in .txt and .srt format, using standardized name, e.g. S01E01_John_per-word.txt and S01E01_John_per-word.srt, as well as S01E01_John_per-sentence.txt and S01E01_John_per-sentence.srt

    - timestamps for each file should be combined into a unified .srt and .txt file, ordered by time, where each block is labeled with the speaker name only when it starts. If there are few blocks for the same speaker, then only the first one should be labeled with the speaker name

    - max line lenght should be between 35 and 42 characters, to maintain readability

2. planned steps [and required functions in Python]:

    - count the number of .wav files in the folder [this will be the number of iterations for generating transcripts]

    - transcribe each .wav file, e.g. using whisper.transcribe(str(wav_file), task="transcribe", word_timestamps=True)

    - generate output files for each processed .wav file in .txt and .srt formats

    - save generated files


3. next version:

    - find all .wav files in the folder

    - check if given .wav file has existing transcriptions. If yes, skip the file. If no, transcribe it

    - generate output files for each processed .wav file in .txt and .srt formats

    - save generated files


4. addition:

    - option to recursively scan subfolders/subcatalogs and gerenate transcriptions only when there is no matching transcription file

5. another version (maybe with different model than Whisper):

    - transcripts of audio files with more than one speaker, with automatic assignation of speaker ID (may be random, as it's easy to fix in manual review). It's important, since sometimes I receive audio recordings extracted from video recordings, so there is no way to separate the channels

    - diarization is needed

    - find similar (may be commercial) solutions for transcripts to check what options do they have, and maybe to look for hints on how they manage the speakers
