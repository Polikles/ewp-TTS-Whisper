# Archived MVP validation material

These files preserve Phase 0–9 spikes, dependency experiments, GPU benchmarks, recovery
exercises, subtitle retests, and release acceptance procedures used to qualify the MVP.

They are historical evidence, not current installation or usage instructions. Commands,
expected commit IDs, relative links, paths, and dependency assumptions are frozen at the
time of their original run and may no longer match `main`.

Current operator documentation lives in [`../../WSL config/`](../../WSL%20config/README.md).
Accepted decisions and sanitized results remain authoritative in [`../../docs/adr/`](../../docs/adr/).
