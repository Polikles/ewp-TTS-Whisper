# v0.4 timed-event semantics

Status: implemented and consumed by the qualified YTT and HTML renderers.

## Contract

Canonical result schema `1.1` adds `kind` to each timed transcript segment. Its closed initial
vocabulary is:

- `speech`
- `music`
- `laugh`
- `cough`
- `note`

The field belongs on a segment because a segment already owns stable timing, text, speaker and
word mappings. A separate parallel event timeline would create ambiguous ordering and duplicate
timing ownership for the first YTT/HTML implementation.

Schema `1.0` artifacts remain valid. When `kind` is absent, the strict domain model interprets
the segment as `speech`. Newly generated canonical results identify themselves as schema `1.1`
and serialize the explicit default. Unknown kinds fail strict model/schema validation.

`kind` is semantic transcript data only. It does not contain brackets, labels, colors, italics,
positioning, or other presentation. Existing TXT, SRT and VTT output continues rendering text
without inventing presentation from the kind or from punctuation.

## Revision and export behavior

Revision tokens inherit kind from their mapped canonical segment. Inserted tokens inherit the
single kind of their canonical neighbors. A revision token may not combine source words from
different kinds. Effective segment reconstruction groups on kind as well as speaker/overlap, so
adjacent kinds cannot collapse into one segment or subtitle planning chain.

Derived segment JSON is schema `1.1`, emits `kind` on every turn, and never merges adjacent
segments with different kinds. Subtitle cue planning retains kind for YTT, while HTML emits
machine-readable `data-kind`; current SRT/VTT bytes remain presentation-compatible.

Canonical non-speech authoring/editing is deliberately not inferred from ASR text. A later
explicit review/editor operation may assign kinds, but it must preserve immutable lineage and
must never guess semantics from brackets or punctuation.

## Acceptance evidence

Automated tests cover legacy defaulting, the closed vocabulary, raw effective resolution,
revision inheritance and reconstruction, kind-sensitive segment turns, cue propagation,
schema validation, and unchanged presentation behavior.
